# Here we will define how Blankchain looks.

It is one of the next steps of Phase 0. The inspiration is the page chiostro.legal/sicurezza, but only for the style: layout, palette, typefaces and spacing. We do not copy texts, logo, images or brand identity. Blankchain's identity will be original.

The documents already use these conventions, ready to be carried over to the site:

- a small `<small>` label above each section title;
- large, declarative titles, ending with a period;
- short paragraphs and a single reading column;
- boxes that state the limits, such as "What it cannot prove";
- cards for the items of a list, such as the levels and the trivial explanations;
- compact badges for the levels: `L0`, `L1`, `L2`, `L3`;
- the update date at the top.

The site will also use cards for the contributions on the Wall.
