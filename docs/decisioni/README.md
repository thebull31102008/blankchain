# Ogni scelta importante ha una scheda con la sua data.

Ogni scheda dice che cosa abbiamo deciso, quando, perché, quali alternative abbiamo scartato e che cosa comporta. Le schede non si cancellano: una decisione superata si segna come tale e rimanda a quella nuova.
